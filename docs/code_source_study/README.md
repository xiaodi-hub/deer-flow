# 源码学习档案规范

本目录保存 DeerFlow 源码学习单元的学习档案。

## 语言规则

- 所有新增或更新的学习档案必须使用简体中文。
- 保留源码中的标识符、文件路径、URL、API 名称和必要的技术术语原文，避免改变其精确含义。
- 每项结论应明确区分“源码事实”“框架知识”和“推断”。
- 文档中的每个源码引用必须使用可点击的绝对路径链接，并定位到对应符号的起始行；仅有路径而不可跳转的代码文本不作为引用。

## 每个 90 分钟单元的最低内容

- 学习目标、前置知识、阅读顺序
- 基于真实请求链路的源码结论，附文件、符号和必要行号
- 状态、调用、输出、异常/边界与设计取舍
- 生产级考量：流式、并发、隔离、恢复、可观测性、安全、扩展性与测试
- 可直接追加到学习档案的笔记结构、5 个复述问题和下一单元建议
